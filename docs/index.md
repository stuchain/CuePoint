# CuePoint Documentation

**Start here:** [README.md](README.md) is the main documentation index (user docs, developer docs, release, compliance).

CuePoint keeps a library of your Rekordbox collection, matches it to Beatport and helps you keep it clean (**Clean**), organizes it with Collections and tags, and plays it. **Discover** finds new music on Beatport from your artists and labels, keeps a wantlist, pushes tracks to a Beatport playlist, and opens an artist's or label's page and similar tracks from any track. **Prepare** plans a set as a running order in chapters, with planned times, checks on every transition and suggestions for any gap.
